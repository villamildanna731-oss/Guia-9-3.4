**Puesto de Chance API** es el backend (API RESTful) de un sistema de punto de venta para juegos de azar (Chance y Baloto). Este sistema permite administrar de forma segura y trazable el inicio de sesión, la venta de tickets, las anulaciones, los cierres de caja y la liquidación de premios.

Este repositorio ha sido documentado bajo los estándares de calidad de software, incluyendo una matriz de trazabilidad de requisitos y documentación técnica de sus módulos.

## 1. Requisitos del Sistema
Para ejecutar este proyecto, asegúrate de tener instalado:
- **Node.js**: versión `v18.0.0` o superior.
- **npm**: versión `v9.0.0` o superior.
- **Git**: para el control de versiones.
